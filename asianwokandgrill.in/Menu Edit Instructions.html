Menu Edit Instructions

This document includes a ready-to-send HTML email draft and complete instructions for updating menu prices through Google Sheets.

Ready-to-Send Email Draft (HTML Style)

Subject: How to Update Menu Prices via Google Sheet
Hi [Client Name], Hope you are doing well. To make menu price updates quick and easy, all your live menu pages are connected to dedicated Google Sheets. You only need to edit prices in the sheet, and the website menu will reflect updates automatically. Please use the correct sheet for each menu from the table below. How to update prices: 1. Open the required Google Sheet. 2. Find the item row and the relevant price column. 3. Change only the price value (numbers only, for example: 249). 4. Do not rename headers, delete columns, or change the sheet structure. 5. Google Sheets saves automatically. 6. Wait 2-10 minutes, then refresh the website page (hard refresh recommended). Important: - Keep item names and categories consistent. - Avoid adding currency symbols (Rs, INR, etc.) in numeric price cells. - If you need to add a new dish, please keep the same format as existing rows. If you need help with any update, reply to this email and we will assist right away. Regards, [Your Name] [Company / Team Name]

Complete Editing Instructions

  1. Open the correct Google Sheet from the table above.
  2. Search for the menu item row you want to update.
  3. Edit only the required price cell(s).
  4. Use plain numbers for prices (example: 199, 249, 399).
  5. Do not change header names, column order, or tab names.
  6. Do not remove existing rows unless a dish has permanently been removed.
  7. If adding a new item, copy an existing row and update values to maintain format consistency.
  8. Wait a few minutes, then open the live menu page and refresh to verify changes.
Important: Structural edits to the sheet (renaming columns, deleting required columns, changing sheet format) can break menu loading on the website.
Tip: After editing, use Ctrl+F5 (Windows) to hard refresh the menu page and confirm the latest prices are displayed.

Quick Verification Checklist

  • Correct item updated in the correct sheet.
  • Price entered as number only.
  • No unintended edits in adjacent columns.
  • Live page refreshed and checked.
  • At least one category and one item confirmed visually on website.
